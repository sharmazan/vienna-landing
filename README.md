# Vienna Apartments Landing Page

A modern, responsive one-page landing website designed to promote apartments for rent in Vienna, Austria.

## Features

- **Hero Section**: Eye-catching introduction with call-to-action
- **Features Section**: Highlights key apartment amenities
- **Location Section**: Showcases Vienna's attractions and location benefits
- **Contact Form**: Allows potential tenants to get in touch
- **Responsive Design**: Optimized for all device sizes using Tailwind CSS
- **Smooth Scrolling**: Enhanced navigation experience

## Technologies Used

- HTML5
- CSS3 (Tailwind CSS via CDN)
- JavaScript (Vanilla)

## How to View

1. Open `index.html` in your web browser
2. For a better development experience, use a local server:
   - Python: `python -m http.server 8000`
   - Node.js: `npx http-server`
   - Or any other static file server

## Customization

- Replace placeholder images with actual apartment photos
- Update contact form to integrate with your backend/email service
- Modify colors and styling in the HTML classes
- Add more sections as needed
